# BUSY Back-end

O segundo trabalho do curso teve como foco a construção de uma aplicação back-end utilizando Java e Eclipse, integrando conceitos de banco de dados, engenharia de software e sistemas inteligentes. O projeto foi desenvolvido com o objetivo de ampliar a solução do primeiro período, que consistia em uma solução voltada à experiência de uso de transporte urbano e pagamentos digitais, para uma abordagem mais robusta, incluindo API, estrutura de dados, manipulação de informações em banco e integração com ferramentas inteligentes.
