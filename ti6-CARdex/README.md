# CARdex

O car spotting é uma prática popular entre entusiastas de automóveis, que consiste em registrar e compartilhar fotos de veículos considerados raros, exclusivos ou interessantes. Entretanto, a experiência atual é fragmentada em redes sociais, sem mecanismos de organização, gamificação ou integração social estruturada. Este trabalho apresenta o CARdex, um sistema inteligente que utiliza técnicas de visão computacional para identificar automaticamente marca e modelo de veículos, permitindo ao usuário montar uma coleção digital própria, comparar registros e interagir com outros entusiastas. O sistema combina um modelo EfficientNet-B3 treinado em 742 classes automotivas, uma arquitetura distribuída composta por React, Render, Cloudflare Tunnel e Google Colab, além de um banco de dados para gerenciamento de usuários e coleções. Resultados indicam acurácia de 89.76% no conjunto de validação e funcionamento consistente da comunicação distribuída entre os módulos.
